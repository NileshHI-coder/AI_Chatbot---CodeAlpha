# AI ChatBot using Java Swing

A GUI-based AI ChatBot developed using Java Swing for interactive communication.  
This project was created as part of the CodeAlpha Java Programming Internship.

---

## Features

- Interactive AI ChatBot
- GUI using Java Swing
- Real-time user interaction
- NLP-style keyword matching
- Rule-based AI responses
- Frequently Asked Questions handling
- Date and Time responses
- Joke command
- Google Search integration
- YouTube Search integration
- GitHub Search integration
- Open websites directly from chatbot
- Clear chat functionality

---

## Technologies Used

- Java
- Java Swing
- OOP Concepts
- Event Handling
- Desktop API
- NLP Basics
